# team-status — 팀 현황

모든 개발자의 `handoffs/<id>/LATEST.md` · 미완 작업(`topics/` 진행 중 + 완료 조건 `[ ]`) · `TODO.md`(사용자가 등록한 것)를 읽어 보고한다. **읽기만 한다** — 누구의 파일도 고치지 않는다.

## 1. 모으기

```bash
node packs/core/bin/team-status.js            # 전체 (git fetch 후 원격 기준 — 작업 폴더는 바꾸지 않는다)
node packs/core/bin/team-status.js --id <id>  # 한 사람의 LATEST · 미완 작업 · TODO 전문 (번호 · 인수 여부)
```

- 기준은 워크스페이스 원격(upstream)이다. 아직 push 하지 않은 남의 핸드오프는 보이지 않는다 — 그 사실을 보고에 적는다.
- 본인 폴더는 이 PC 작업 폴더 것을 쓴다 (push 전일 수 있다).

## 2. 보고

```
팀 현황 (YYYY-MM-DD, 기준: <원격>)
| 개발자 | 마지막 핸드오프 | 핵심 | 진행 중 · 작업 브랜치 | 미완 작업 | TODO |
주의: {N일째 갱신 없음 · 이 PC 에만 있는 진행 중 작업(브랜치 push 안 됨) · 겹칠 수 있는 작업}
➡️ 제안: {인수가 필요해 보이는 항목 — takeover(인수인계) <id>}
```

- 3일 넘게 갱신 없는 사람, "이 PC 에만 있음" 으로 적힌 작업 브랜치는 **주의**로 올린다 (그 사람이 없으면 코드를 받을 수 없다).
- 인수된 항목은 "인수됨 → <누구>" 로 센다. 판단·배정은 하지 않는다 — 사실과 제안만.
