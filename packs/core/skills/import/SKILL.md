# import: 기존 AI 작업 폴더 가져오기

예전 폴더를 통째로 복사하지 않는다. **훑기 → 계획 → 승인 → 옮기기 → 점검** 순서로, 원본은 건드리지 않는다.

## 1. 훑기

```bash
node packs/core/bin/import-scan.js <기존 폴더>          # 분류 보고 (읽기만)
node packs/core/bin/import-scan.js <기존 폴더> --json   # 전체 목록
```

보고에 나오는 것: 지침 · 룰 / 스킬 · 명령 · 역할 / 메모 / 핸드오프 · 할 일 / 훅 · 설정 / 스크립트 / 큰 폴더(산출물 후보) / 문서 속 개인 폴더 절대경로 / 비밀값 의심 줄(값은 찍지 않는다).

## 2. 계획 세우기

지침 · 룰은 파일째가 아니라 **내용 단위**로 읽고 아래로 나눈다.

| 판정 | 기준 | 옮길 곳 |
|---|---|---|
| 버림: 킷과 겹침 | 같은 뜻의 규칙이 `AGENTS.md`(상시 룰)나 `.agents/rules/` 색인에 있다 | 옮기지 않는다 (계획 표에 무엇과 겹치는지 적는다) |
| 버림: 코드로 알 수 있음 | 폴더 구조 · 의존성 · 빌드 명령처럼 repo 를 읽으면 나오는 것 | 옮기지 않는다 |
| 상시 | 이 프로젝트에서만 통하고 매 작업에 필요한 사실 · 금지 (환경 이름, 운영 접근 금지, 개인정보 처리) | `packs/project/rules/00-project.md` |
| 필요할 때 | 특정 작업 · 경로에서만 쓰는 규칙 (배치, 특정 모듈 관례) | `packs/project/rules/<번호>-<이름>.md` (`load: on-demand` 와 읽는 조건) |
| 개인 | 한 사람만 따르는 것 | `.agents/local.md` |

나머지는 이렇게 본다.

| 대상 | 처리 |
|---|---|
| 스킬 · 명령 | 킷 기본 스킬과 같은 일이면 버리고, 프로젝트 고유 절차만 `packs/project/skills/<이름>/SKILL.md` |
| 메모 | 아직 맞는 사실만 골라 위 룰 판정으로. 날짜 지난 진행 상황은 버린다 |
| 핸드오프 · 할 일 | 끝나지 않은 것만 `handoffs/<내 id>/` 로 (`handoff` 스킬 형식). 옛 기록은 원본에 둔다 |
| 스크립트 | 팀이 쓰는 도구는 `packs/project/bin/`, 개인 1회용은 `scripts/` (`.agents/rules/core--41-context-detail.md`) |
| 큰 폴더 | 다시 만들 수 있으면 옮기지 않고 만드는 스크립트만 옮긴다. 다시 만들 수 없는 자료는 기획 repo 로 |
| 훅 · 설정 | 킷이 만드는 설정과 겹친다. 그대로 옮기지 않고, 꼭 필요한 것만 사용자와 정한다 |
| 절대경로 | 워크스페이스 기준 상대 경로나 `repos/<이름>/…` 로 바꾼다. 바꿀 수 없으면 목록에 남긴다 |
| 비밀값 의심 줄 | 옮기지 않는다. 필요한 값은 `aikit secret` 으로 넣고 문서에는 이름만 적는다 |

계획은 표로 보여 준다: **원본 → 옮길 곳 · 판정 · 바뀌는 것(경로 치환 · 뺀 줄)**, 그리고 버리는 것 목록과 비밀값 의심 줄 위치. 사용자가 승인한 뒤에 옮긴다. 판정이 갈리는 항목은 선택지 질문으로 따로 묻는다.

## 3. 옮기기

- 승인받은 계획대로만 옮긴다. 원본 폴더는 고치거나 지우지 않는다.
- 상시 룰에 넣는 양은 작게 유지한다 (팩당 약 6KB). 길면 필요할 때 읽는 룰로 나눈다.
- 옮긴 문서에 원본 경로 · 날짜를 주석으로 남기지 않는다. 출처는 계획 표와 커밋 메시지로 충분하다.

## 4. 점검

```bash
node bin/kit.js sync && node bin/kit.js check
node packs/core/bin/check-refs.js
node packs/core/bin/import-scan.js . | grep -A20 "절대경로\|비밀값"   # 옮긴 뒤 남은 것
```

보고: 옮긴 것 · 버린 것(이유) · 남은 절대경로 · 비밀값은 옮기지 않았다는 것 · 사용자가 `aikit secret` 으로 넣을 값 목록. 커밋은 사용자가 요청할 때 한다.
