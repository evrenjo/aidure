# cross-review — 다른 벤더 에이전트의 두 번째 의견

같은 모델은 같은 사각지대를 가진다. 변경·설계·질문을 **다른 벤더의 CLI** 에 읽기 전용으로 보여 주고, 두 의견을 근거로 맞춘다.

- 리뷰 지침은 `packs/core/agents/reviewer.md` 본문을 그대로 쓴다 (도구가 프롬프트에 싣는다).
- **읽기 전용** — Codex 는 `--sandbox read-only`, Claude Code 는 `--permission-mode plan` + 읽기 도구(Read·Grep·Glob)만.
- **비용** — 상대 CLI 는 사용자 본인의 구독·API 로 돈다. 큰 diff 는 비용과 시간이 크다 (최대 10분, 프롬프트 400KB 에서 자름). 돌리기 전에 범위와 대상을 한 줄로 알리고 확인받는다.

## 1. 범위 정하기

| 범위 | 인자 |
|---|---|
| 지금 변경 (기본) | 없음 — 워크스페이스 `repos/*` 중 변경이 있는 repo 들, 없으면 현재 repo 의 `HEAD` 대비 변경 + 추적 안 된 파일 |
| 브랜치 전체 | `--base <ref>` (예: 통합 브랜치) |
| 특정 파일 | `--files a.js,b.js` |
| 질문 · 설계 의견 | `--question "..."` (변경과 함께 또는 단독) |

목적이 있으면 `--question` 에 적는다 ("이 수정이 동시 저장에서도 맞는가?"). 목적 없는 리뷰보다 발견이 정확하다.

## 2. 실행

```bash
node packs/core/bin/cross-review.js --dry-run            # 대상 벤더·명령·프롬프트 크기만 확인
node packs/core/bin/cross-review.js                       # 실행 (--to auto)
node packs/core/bin/cross-review.js --to claude --base origin/main --question "..."
```

- `--to auto`(기본) 는 호출한 쪽의 반대 벤더를 고른다. 호출자를 알 수 없으면 설치된 쪽을 쓴다 — `--dry-run` 첫 줄에 고른 이유가 나온다. 틀렸으면 `--to` 로 지정한다.
- 모델은 `--model`, 없으면 프로필·`workspace.json`·`.agents/local.json` 을 합친 교차 검토 모델(`kedovi models` 에 보이는 값), 그것도 없으면 그 CLI 의 기본값.
  추론 강도는 `--effort`, 없으면 같은 자리의 `effort`.
- 상대 CLI 가 없거나 로그인이 안 돼 실패하면 오류를 그대로 보여 주고 멈춘다. 대신 같은 벤더로 돌려 "교차 리뷰" 라고 부르지 않는다.

> Claude Code: 상대는 Codex. `codex` 가 설치·로그인돼 있어야 한다.
> Codex: 상대는 Claude Code. `claude` 가 설치·로그인돼 있어야 한다. 샌드박스가 외부 명령·네트워크를 막으면 사용자 승인을 받아 실행한다.

## 3. 결과 맞추기 — 그대로 받아쓰지 않는다

상대의 발견도 **주장**이다. 각 발견을 직접 코드로 확인해 판정한다.

1. 발견마다 해당 `파일:라인` 을 열어 본다. 틀리는 입력·경로를 재현할 수 있으면 **확인됨**, 못 하면 **추정**, 사실과 다르면 **기각**(이유와 근거).
2. 내 판단과 다르면 양쪽 근거를 나란히 놓는다. 근거가 더 강한 쪽을 따르고, 판정이 안 되면 사용자에게 선택지로 묻는다.
3. 상대가 못 본 것(내가 이미 확인한 결함)도 함께 적는다 — 한쪽만 찾은 것이 가장 쓸모 있는 정보다.
4. 고치는 것은 사용자가 요청할 때만. 이 스킬은 의견을 모으는 데까지다.

## 4. 보고

```
결론: 상대(<벤더>/<모델>) 발견 N건 — 확인됨 A · 추정 B · 기각 C / 나만 찾은 것 D건
| # | 파일:라인 | 상대 의견 | 내 판정 | 근거 |
두 의견이 갈린 것: <항목 — 양쪽 근거, 결정 필요 여부>
범위: <검토한 repo·기준·파일> / 실행 명령
```

상대가 발견 없음이라고 하면 그대로 적되, 검토한 범위(잘림 여부 포함)를 함께 밝힌다.
