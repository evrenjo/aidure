## ML · AI 코드

- **노트북은 탐색용.** 재사용 로직은 모듈(`src/` 등)로 옮기고 노트북은 import 해서 쓴다. 공유 전 "재시작 후 전체 실행" 으로 확인한다 (숨은 상태 · 실행 순서 때문에 재현이 안 되는 노트북이 대부분이다).
- **실험 값은 한 곳.** 하이퍼파라미터 · 경로 · 모델 이름은 설정 파일 · 설정 객체 하나로. 코드에 흩지 않고 라이브러리 기본값에 기대지 않는다.
- **재현성:** 시드를 한 곳에서 고정(random · numpy · torch)하고, 데이터 버전 · 설정 · 코드 커밋을 결과와 함께 남긴다.
- **학습과 서빙은 같은 전처리 코드를 쓴다.** 전처리 fit 은 학습 분할에만 (데이터 누수 금지).
- 단계(적재 · 전처리 · 학습 · 평가 · 추론)를 함수로 나누고, 텐서 · 배열 모양을 이름이나 주석으로 적는다 (`# (batch, seq, dim)`).
- **pandas:** 체인 인덱싱 대신 `.loc`, `inplace=True` 대신 대입, `merge` 는 `on` · `how` 명시, 반복문 대신 벡터 연산, NaN 은 `isna()`.
- **PyTorch:** `model(x)` (`.forward` 직접 호출 금지), `train()` · `eval()` 전환, 역전파 전 `zero_grad()`, 추론은 `torch.inference_mode()`.
- **LLM 앱:** 프롬프트는 템플릿 파일 · 상수로 분리해 버전을 관리한다. 출력은 스키마(Pydantic 등)로 검증, 모델 이름 · 온도는 설정으로, 재시도 · 시간 제한을 둔다.
- 죽은 실험 분기 · 쓰지 않는 특성은 지운다.
