## 공통

- **스토어 점검표가 기준이다** — 제출 전에 그 플랫폼의 최신 점검표를 다시 읽는다. 기준은 자주 바뀐다(여기 수치는 조사일 기준).
- **입력 기기를 필수로 선언하지 않는다** — 터치스크린·카메라·마이크·GPS 등. 필수 선언은 TV 에 설치·노출되지 않게 만든다.
- **권한·특권 선언은 필요한 것만** 더하고, 더한 이유를 변경 설명에 적는다.

## 플랫폼별 선언

| 플랫폼 | 확인할 것 |
|---|---|
| Android TV | 진입 Activity 에 `ACTION_MAIN` + `CATEGORY_LEANBACK_LAUNCHER`(없으면 TV 런처·TV 용 Play 에 안 보인다). `android.hardware.touchscreen` 을 `required="false"` 로. 권한이 암시하는 기능(`RECORD_AUDIO`→마이크, `CAMERA`, 위치→GPS, Wi‑Fi)도 `required="false"` 로 선언. 휴대폰 겸용이면 `android.software.leanback` 은 `required="false"`. `<application android:banner>` 320×180px(xhdpi), 배너에 앱 이름 |
| tvOS | Siri 리모컨(또는 서드파티 게임 컨트롤러)만으로 쓸 수 있어야 한다. 게임 컨트롤러가 필수면 스토어 정보에 명시 |
| Samsung Tizen | 보안 민감 API 의 특권(privilege)을 `config.xml` 에 선언(예: 추가 키 등록은 `tv.inputdevice`). 멀티태스킹 구현 필수 |
| LG webOS | `appinfo.json` 필수 항목(`id`·`title`·`type`·`main`·`icon`·`version`). `id` 는 소문자·숫자·`-`·`.` 만, 버전은 세 자리 형식. 뒤로 키 처리 방식(`disableBackHistoryAPI`)·재실행 처리(`handlesRelaunch`)를 코드와 맞춘다 |

## 런처·홈 연동

- **런처 아이콘·배너는 플랫폼 규격대로** — 해상도·크기를 지키고 4K 기기용 고해상도 자산을 둔다.
- **홈 화면 추천·이어 보기**(Android TV Engage SDK, tvOS Top Shelf·TV 앱 연동 등)는 프로젝트가 이미 쓰는 방식을 따른다. tvOS Top Shelf 에는 광고·가격을 두지 않고, 이미 본 콘텐츠를 홍보하지 않는다.
- 홈에서 들어온 콘텐츠는 바로 재생(`30` 룰 "이어 보기·실행 경로").

## 광고·웹 콘텐츠 (Android TV 기준)

- 광고는 방향키로 조작되고, 전체 화면 비영상 광고는 방향키로 즉시 닫을 수 있어야 한다. 광고가 웹 URL 이나 TV 에 없는 앱으로 연결되지 않게 한다.
- 웹 콘텐츠는 앱 안의 `WebView` 로만 보여 준다. 브라우저 앱을 띄우지 않는다.

## 스토어별 점검표 요점

| 스토어 | 요점 |
|---|---|
| Android TV (TV app quality) | 런처 아이콘·배너, 가로 전체 화면·잘림 없음, 방향키로 전 기능, 메뉴 키 비의존, 뒤로는 홈으로, 재생 키 동작, 영상은 앱을 떠나면 일시정지, 저메모리 기기 메모리 한도, 로그인이 필요하면 심사용 계정 제출 |
| Samsung (Development Checklist) | 오류·멈춤 없음, 네트워크 끊김 알림, 재생 중 화면 보호기 없음, 자막 동기화, 멀티태스킹, 실행 10초 이내, 특권 선언, 뒤로·Exit 키 정책, 방향키로 모든 요소 포커스, 제거 시 계정 등 사용자 데이터 삭제 |
| LG webOS (App Self Checklist) | 필수: 방향키·확인·뒤로 모두 동작, 화면 커서(포인터) 동작, 모든 객체에 선택 효과, 첫 화면 뒤로 동작. 권장: 버튼·글자 최소 크기, 로딩 표시, 재생 컨트롤. 코드·파일 이름에 비밀번호·토큰·키가 드러나지 않을 것. 점검표는 최신 양식으로 제출 |
| Apple (App Review Guidelines) | 2.4.3 — Siri 리모컨·게임 컨트롤러 외 하드웨어를 요구하지 않는다 |

## 테스트 환경

- **최종 확인은 실기기에서.** 에뮬레이터·시뮬레이터 제약이 크다 — webOS 시뮬레이터는 DRM 미지원·오디오/비디오 사양이 다름, Samsung TV 에뮬레이터는 실기기보다 느리고 일부 API·길게 누르기·UHD 를 지원하지 않는다.
- 리모컨(또는 에뮬레이터의 가상 리모컨)만으로 설치 → 첫 실행 → 주요 흐름 → 숨김·복귀 → 네트워크 끊김 → 제거·재설치를 돈다. 마우스로 대신 누르지 않는다.
- 저사양 기기(또는 저메모리 설정)에서 한 번 돌린다. 못 돌린 플랫폼·기기는 미확인으로 보고한다.
