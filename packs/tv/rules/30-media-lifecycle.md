## 먼저 볼 것

그 프로젝트의 플레이어 래퍼·수명주기 처리 위치를 찾는다. 플랫폼 기본 플레이어(tvOS 시스템 플레이어, Android Media3·ExoPlayer, Tizen AVPlay, 웹 `<video>`·MSE)를 쓰고 있으면 그 위에서 고친다. **플랫폼 기본 플레이어가 있으면 우선하고**, 커스텀 플레이어는 기본 플레이어의 조작 방식을 따라 만든다.

## 재생 조작

- 확인(가운데) 키 = 재생·일시정지 전환, 좌우 = 되감기·빨리감기, 재생·일시정지 키 = 토글. 화면 위 재생 컨트롤을 두고 전부 방향키로 닿게 한다.
- 영상 위 로고·안내는 작고 짧게. 상호작용 오버레이는 재생을 멈춘 뒤 띄우고 닫는 방법을 분명히 둔다.
- 영상은 원래 화면비로. 남는 여백은 검은색만.
- **재생 중에는 화면 보호기·앰비언트 모드가 뜨지 않게, 재생이 아닐 때는 막지 않는다.** 음악만 재생할 때는 막지 않는 것이 기본(Android TV).
- 자막이 있으면 영상과 동기화한다.

## 앱이 숨겨질 때·돌아올 때

| 플랫폼 | 신호 | 숨겨질 때 |
|---|---|---|
| Android TV | Activity `onStop` | 영상은 정지하고 미디어 자원을 바로 해제. 음악을 계속 틀면 시스템 미디어 컨트롤(MediaSession) 제공 — 영상은 이 방식을 쓰지 않는다 |
| tvOS | 앱 수명주기(비활성·백그라운드), 보조 오디오 신호 | 화면 전환·PiP 사이에 다른 앱 오디오와 섞이지 않게 보조 오디오 신호를 처리 |
| Samsung Tizen | `visibilitychange`(`document.hidden`) | 상태를 메모리에 두고 숨김. 재생 중이면 뒤로 키와 같은 동작(대개 정지 후 이전 화면) |
| LG webOS | `visibilitychange`, 재실행은 `webOSRelaunch` | 미디어 일시정지·자원 해제·불필요한 작업 중단. `handlesRelaunch` 로 재실행 처리 여부 지정 |

돌아올 때:

- **네트워크 연결을 다시 확인한다.** 끊겨 있으면 네트워크 작업을 멈추고, 알림을 띄우고, 재연결을 기다린다. 재생 중 끊김·재연결에서 멈추지 않아야 한다.
- **오래 숨겨져 있었으면 로그인 세션·DRM 라이선스·콘텐츠 URL 만료를 확인**하고 새로 받는다.
- 재생을 복구할 수 있으면 복구한다(플레이어 일시 중단·복원 API 가 있으면 사용).

## 이어 보기·실행 경로

- 이어 볼 수 있으면 **묻지 않고 이전 위치에서** 이어 재생한다(tvOS 권장).
- 홈·런처·시스템 TV 앱에서 콘텐츠를 골라 들어오면 **스플래시·상세 화면 없이 바로 재생**한다. 재생을 끝내면 방금 본 콘텐츠의 상세(이어 보기 포함)로.
- 로딩이 길면 검은 배경 + 가운데 진행 표시만. 충분히 받으면 바로 재생을 시작하고 나머지는 뒤에서 받는다.
- 여러 프로필이면 요청된 프로필로 전환한 뒤 재생한다.

## DRM

- **지원 DRM·포맷 조합은 플랫폼·OS 버전마다 다르다** — 방식(Widevine·PlayReady·ClearKey 등)을 고르거나 바꾸기 전에 대상 플랫폼의 지원표를 확인한다.
- DRM 설정은 플레이어가 요구하는 시점(예: 준비 전 상태)에 넣는다.
- 라이선스 URL·토큰·키를 로그·오류 화면·저장소에 남기지 않는다. 라이선스 서버 요청은 프로젝트의 기존 인증 방식을 따른다.
- 시뮬레이터·에뮬레이터는 DRM 을 지원하지 않거나 다르게 동작한다 — **DRM 재생은 실기기에서 확인한다.**

## 메모리·성능

- **화면 해상도보다 큰 이미지를 싣지 않는다** — 720p UI 기기에 1080p 이미지를 싣지 않는다. 자리 표시 이미지 대신 단색.
- **플레이어·미디어 버퍼는 에피소드 전환·정지 때 바로 해제한다.** 버퍼 크기는 기기 메모리·해상도에 맞춘다.
- 저사양 기기 기준을 확인한다 — 예: Android TV 저메모리(1GB) 기기의 전경 앱 합계 280MB 이하. webOS 는 `requiredMemory` 로 필요 메모리를 선언한다.
- tvOS 는 로컬 영구 저장이 작다(`UserDefaults` 약 500KB). 나머지는 지워질 수 있는 캐시로 보고, 사용자 데이터는 클라우드에 둔다.
- 실행 시간을 잰다 — Samsung 은 10초 이내 필수(5초 권장). 오래 켜 두어도 느려지지 않는지 본다.
