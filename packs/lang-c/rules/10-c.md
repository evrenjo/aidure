## C 클린 코드

먼저 이 repo 의 관례(커널 · GNU · BARR-C · MISRA 등)와 `.clang-format` · 컴파일 옵션을 따른다. 아래는 관례가 없을 때의 기본값이다.

- **이름:** `snake_case`, 상수 · 매크로는 `UPPER_CASE`. 공개 함수는 모듈 접두사 (`uart_send`). 지역은 짧게, 전역은 설명적으로. 헝가리안 표기 금지.
- **함수:** 한 가지 일, 한 화면 안. 동작 함수는 오류 코드, 판정 함수는 `bool` (`is_` · `has_`). 출력 인자는 맨 뒤, 입력 포인터는 `const`.
- **구조체 · 모듈:** 헤더 = 공개 API, 내부는 `static`. 불투명 포인터로 숨긴다. 포인터 `typedef` 금지. 헤더는 include guard, 자기 의존을 직접 include.
- **주석:** 무엇 · 왜 를 쓰고 어떻게 는 코드로. 공개 API 는 Doxygen (`@param` · `@return` · 소유권 · NULL 허용 여부).
- **읽히는 코드:** 이른 반환으로 중첩을 줄인다. 매직 넘버는 `enum` · `const` 이름으로. 긴 조건은 이름 있는 `bool` 이나 함수로. 한 줄에 한 문장, 블록은 항상 중괄호.
- **메모리 · 오류:**
  - 반환값을 모두 확인한다 (`malloc` · I/O · `snprintf`). 버릴 때는 `(void)` 로 드러낸다.
  - 할당한 곳과 같은 층에서 해제한다. 정리 경로가 여럿이면 `goto out_*` 하나로 모은다 (repo 관례가 다르면 그것).
  - 해제 뒤 `NULL` 대입, 크기는 `size_t`, 곱셈 · 덧셈 넘침 확인. 문자열은 길이를 함께 넘긴다.
  - 변수는 선언하며 초기화하고 범위를 좁힌다. 함수형 매크로 대신 `static inline`.
- 빌드 설정이 C23 이면 `nullptr` · `bool` · `constexpr` · `[[nodiscard]]` 를 쓴다. 그보다 새 기능은 쓰지 않는다.
- **하지 않는 것:** `gets` · `strcpy` · `sprintf` · `strtok`, 경고 끄기, 정의되지 않은 동작에 기대기(부호 있는 넘침 등). 임베디드 · 안전 등급 repo(MISRA 설정 · freestanding · RTOS)면 동적 할당 · 재귀도 쓰지 않는다.
- 경고는 `-Wall -Wextra` 수준으로 0개를 유지하고, 테스트 빌드가 있으면 ASan · UBSan 으로 돌린다.
