## 권한

- **꼭 필요한 권한만 더한다** — 다른 앱에 맡겨 끝낼 수 있는 일(연락처 추가, 사진 고르기 등)은 권한 대신 시스템 인텐트·선택기로. 더한 권한과 이유를 변경 설명에 적는다.
- **그 기능을 쓰는 순간에 묻는다** — 앱 시작 시 한꺼번에 묻지 않는다(앱의 핵심 기능이라 이유가 뻔한 경우만 예외).
- **쓸 때마다 확인한다** — 사용자는 설정에서 언제든 권한을 거둔다. 한 번 허용받았다고 캐시하지 않는다.
- **거부돼도 앱은 계속 쓸 수 있어야 한다** — 그 기능만 끄고, 전체 화면 경고로 막거나 반복해서 조르지 않는다. 설명 화면에는 항상 취소가 있다.
- Android: 요청 전에 이미 허용됐는지 확인하고, 시스템이 설명이 필요하다고 알리면(`shouldShowRequestPermissionRationale`) 설명을 먼저 보여 준다.
- iOS: 보호 자원(카메라·마이크·사진·위치·연락처 등)마다 **용도 문구 키**가 `Info.plist` 에 있어야 한다. 없이 접근하면 시스템이 앱을 종료한다. 문구는 이 앱이 그 자원을 어디에 쓰는지 구체적으로.
- 권한 허용에 보상을 주거나, 시스템 경고를 흉내 낸 화면을 띄우지 않는다(스토어 심사 거절 사유).

## 개인정보 신고와 코드가 맞아야 한다

- 수집 데이터·추적 여부가 바뀌는 변경(분석·광고 SDK 추가 포함)이면 **신고 항목도 바뀐다** — iOS 개인정보 매니페스트(`PrivacyInfo.xcprivacy`), App Store 개인정보 항목, Google Play 데이터 보안 양식. 서드파티 SDK 가 수집하는 것도 앱의 신고에 들어간다.
- iOS 에서 "사유가 필요한 API" 를 새로 쓰면 매니페스트에 사유를 적는다. SDK 를 더하면 그 SDK 가 자체 매니페스트를 갖고 있는지 본다.
- 신고 양식을 에이전트가 직접 고칠 수 없으면 **"스토어 신고 갱신 필요"** 를 결과에 적는다.

## 로컬 저장

| 데이터 | 어디에 |
|---|---|
| 토큰·비밀번호·암호 키 | **iOS Keychain · Android Keystore**(키는 추출 불가, 가능하면 하드웨어 기반). 이를 감싼 프레임워크의 보안 저장 모듈 |
| 앱 전용 데이터·DB·설정 | 앱 전용 내부 저장소 (다른 앱이 못 읽고 삭제 시 함께 지워진다) |
| 다른 앱과 나눌 미디어·문서 | 플랫폼 공유 저장소 API (Android MediaStore·저장소 접근 프레임워크, iOS 문서·사진 API) |
| 캐시 | 캐시 디렉터리 (OS 가 지울 수 있고 백업에서 빠진다) |

- **평문 설정(`SharedPreferences`·`UserDefaults`·AsyncStorage·`localStorage`)에 토큰을 두지 않는다.**
- Android 외부 저장소(공유 위치)는 다른 앱이 읽을 수 있다 — 민감 정보·실행 코드를 두지 않는다. 외부에서 받은 코드를 동적으로 불러야 하면 서명을 검증한 뒤에만.
- iOS 파일 보호 등급: 사용자 데이터 파일은 가장 강한 등급(기기 잠금 중 접근 불가)을 기본으로 보고, 백그라운드에서 읽어야 하는 파일만 한 단계 낮춘다. 등급을 낮추는 변경은 이유를 적는다.

## 백업

- Android 자동 백업은 기본으로 켜져 앱 내부 파일·DB·설정을 클라우드에 올린다. **기기 고유 식별자·푸시 등록 토큰처럼 기기가 바뀌면 무효가 되는 값, 민감 정보는 백업 규칙으로 뺀다** (Android 12 이상 `dataExtractionRules`, 그 이하 `fullBackupContent` — 둘 다 맞춘다).
- 백업 설정(`allowBackup` 등)을 바꾸면 복원 후 앱이 깨지지 않는지 본다.

## 다른 앱과 주고받기

- Android 컴포넌트는 **`android:exported` 를 명시한다** (Android 12 이상 대상이면 인텐트 필터가 있는 컴포넌트에 필수). 외부에 열 이유가 없으면 `false`.
- 내 앱끼리만 쓰는 제공자·서비스는 **서명 수준 권한**으로 보호한다. 파일은 `file://` 대신 `content://` URI 와 일회성 읽기·쓰기 허가 플래그로 넘긴다.
- 서비스를 부르는 인텐트는 **명시적 인텐트**로. 인텐트 필터는 보안 장치가 아니다 — 받는 쪽에서 입력을 검증한다.
- 콘텐츠 제공자 조회는 매개변수 쿼리로(SQL 주입 방지).
- 권한으로 얻은 데이터를 IPC 로 다른 앱에 흘리지 않는다. 같은 기기 안 통신에 localhost 포트를 쓰지 않는다(다른 앱도 접속한다).
