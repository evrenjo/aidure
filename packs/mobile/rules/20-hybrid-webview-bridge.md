## 경계부터 확인한다

웹뷰에 네이티브 기능이 닿아 있으면, 그 웹뷰에서 도는 **모든 스크립트가 그 기능을 쓸 수 있다**. XSS 한 번이 네이티브 권한 탈취가 된다고 보고 설계한다.
고치기 전에 그 프로젝트의 현재 설정을 읽어 둔다 — 셸 설정 파일, 허용 목록, CSP 가 어디서 오는지, 노출된 플러그인·인터페이스 목록.

## 웹뷰 설정 — 약하게 만들지 않는다

| 항목 | 유지할 상태 |
|---|---|
| 자바스크립트 | 웹뷰가 스크립트를 쓰지 않으면 **켜지 않는다** (Android 기본 꺼짐) |
| `file://` 접근 (Android `allowFileAccess`·`allowFileAccessFromFileURLs`·`allowUniversalAccessFromFileURLs`) | **명시적으로 끔**. 로컬 자산은 `https` 스킴으로 내주는 로더(`WebViewAssetLoader` 류)로 |
| 혼합 콘텐츠(HTTPS 페이지 안 HTTP) · 평문 통신 | **기본값(차단) 유지** |
| 웹 콘텐츠 디버깅 | 배포 빌드에서 **끔** |
| 개발 서버 URL·라이브 리로드·내비게이션 전체 허용 설정 | **개발 빌드에만**. 셸 문서가 "배포용 아님"이라고 적은 옵션은 배포 설정에 남기지 않는다 |
| 자체 서명 인증서 허용 | 쓰지 않는다 — 인증서 체인 검증이 꺼져 중간자 공격에 열린다 |

이 중 하나를 바꾸자는 변경이 필요해 보이면 **멈추고 이유와 대안을 먼저 묻는다.**

## 브리지·플러그인

- **신뢰 콘텐츠에만 연다** — 네이티브 인터페이스는 앱이 번들한 콘텐츠에만 노출한다. 외부 사이트·광고·사용자 HTML 을 브리지가 붙은 웹뷰에 싣지 않는다. 신뢰하지 않는 콘텐츠를 불러야 하면 먼저 인터페이스를 떼거나 브리지 없는 웹뷰를 쓴다.
- Android 자바스크립트 인터페이스는 **iframe 을 포함한 모든 프레임에 주입되고 호출한 출처를 알 수 없다.** 출처 확인이 필요하면 HTML 메시지 채널을 쓰고, 대상 출처에 `*` 대신 기대하는 도메인을 명시한다.
- **기능 단위로 노출한다** — `savePhoto(id)` 는 되고 범용 "명령 실행·파일 읽기·임의 URL 요청" 통로는 안 된다. 민감한 작업·사용자 데이터 조회는 브리지로 열지 않는 게 기본이다.
- **네이티브 쪽에서 인자를 검증한다** — 타입·범위·경로. 경로는 정규화 후 허용 루트 밖이면 거부한다.
- 플러그인을 더할 때 그 플러그인이 여는 권한·기능을 확인한다. 쓰지 않는 플러그인은 뺀다.

## 허용 목록·CSP·내비게이션

- **내비게이션을 신뢰 도메인으로 제한한다** — 셸 기본값이 제한 없음인 경우가 있다(Cordova). 외부 링크는 시스템 브라우저로 열고, 스킴·호스트를 URL 파서로 확인한다.
- **CSP 를 둔다** — 셸 템플릿의 기본 CSP 를 프로젝트에 맞게 좁힌다. `eval`·`unsafe-eval`·원격 스크립트 출처를 더하지 않는다.
- 네트워크 요청 허용 목록(`access`·`allow-navigation`·`allow-intent` 류)은 필요한 도메인만. 와일드카드로 넓히지 않는다.

## 크로스플랫폼 네이티브 연동 (React Native·Flutter·KMP·MAUI 류)

- 네이티브 모듈·플랫폼 채널 처리기는 **플랫폼 메인 스레드에서 불리는 게 기본**인 프레임워크가 있다(Flutter 플랫폼 채널). 무거운 일은 그 프레임워크의 백그라운드 수단(태스크 큐 등)으로 옮긴다.
- 브리지를 건너는 값은 프레임워크 코덱이 지원하는 단순 타입으로. 네이티브 쪽에서 다시 검증한다.
- JS·Dart 쪽 저장소(AsyncStorage·웹 `localStorage` 류)는 **암호화되지 않는다** — 토큰은 Keychain·Keystore 를 쓰는 보안 저장 모듈로.

## 확인

- 배포 빌드에서 웹 콘텐츠 디버깅이 꺼졌는지, 브리지 없는 메서드·허용 밖 도메인 이동이 거부되는지, 외부 링크가 시스템 브라우저로 열리는지 한 번씩 본다.
- Android·iOS 웹뷰 엔진이 다르다. 한쪽만 돌렸으면 미확인으로 보고한다.
