## AS-IS 대조 절차 (저장·복사·조회)

상시 룰(차세대 전환 — AS-IS 정합 원칙)의 절차판이다. 도구 명령은 `packs/modernization/docs/asis-tools.md`.

### ① 계약을 한 줄로 적는다

"파일 N개 수정" 이 아니라 **바뀌는 계약**을 적는다 — 기준 테이블·조인 키·컬럼 의미·정본 위치.
이 한 줄이 이후 전수 검색의 대상이 된다.

### ② AS-IS 문을 찾는다 — 진입점부터

- 화면(EGL 등)은 `add <레코드>` / `#sql{ insert … }`, 배치(COBOL)는 `EXEC SQL INSERT/UPDATE/DELETE` 와 파일 `WRITE`.
- 진입점을 모르면 `asis-reads.js <파일>` 을 인자 없이 부른다 — 읽기를 전부 덮는 **최소 진입점 조합**을 추천한다.
- `asis-effects.js <파일> --entry <진입점,…> --tobe <TO-BE 가 쓰는 표,…>` 로 **쓰는 표 집합**을 뽑아 TO-BE 와 개수부터 맞춘다.
- **`⚠ 폐쇄 밖 쓰기/읽기` · `⚠ 정의 없는 레코드` 가 사라질 때까지 진입점을 넓힌다.** 드라이버가 둘 이상이거나, 드라이버 위에 진짜 진입점이 있어 복사 직후 UPDATE 가 따로 도는 경우가 흔하다.
- **미개봉 함수 0 이 될 때까지가 "닫혔다"** 다 (`--opened` 로 연 것을 넘긴다).

### ③ 컬럼 전수 표

1. INSERT 의 컬럼 목록(UPDATE 면 SET 절 전체)을 그대로 옮긴다.
2. 각 컬럼 호스트 변수의 대입 지점을 `asis-field-writes.js --entry … --field <필드> [--table <표>]` 로 **호출 경로 순**으로 뽑는다.
   - 대입문이 없으면 초기화 기본값이 정답이다.
   - 조건부 대입이면 `--cond`(asis-effects·asis-reads) 로 조건 스택까지 옮긴다. COBOL 은 END-IF 가 완비된 파일에서만 조건 스택을 낸다 — 경고가 뜨면 손으로 본다.
3. 표로 대조한다 — `컬럼 / AS-IS 값(근거 파일:라인) / TO-BE 값(근거 파일:라인) / 판정`. 한 칸이라도 비면 미완료.
4. 같은 컬럼을 쓰는 TO-BE 경로 전부(화면·배치·복사)를 grep 해 같은 표에 넣는다.
5. 마이그레이션 실데이터 `GROUP BY 컬럼` 분포로 교차 확인한다.

### ④ 조회 대조

- `asis-reads.js --entry … [--table T] [--sql] [--cond]` 로 기준 테이블·조인·WHERE 컬럼을 표 단위로 뽑는다. EGL 은 레코드의 `defaultSelectCondition`(숨은 조건)까지 센다.
- 이름이 다르면 `asis-tobe-map.js VIEW.COL` 로 TO-BE 이름으로 잇는다. `--where` 로 **그 뷰가 행을 거르는지(필터 조건) 조인만 하는지** 확인한다.
- `asis-tobe-diff.js --asis … --entry … --tobe <TO-BE 쿼리 파일>` 로 공통 / AS-IS 만 / TO-BE 만 조건을 낸다. 조건이 같다고 동작이 같지는 않다 — 분기·정렬·조인 방향은 직접 본다.

### ⑤ 복사·클론 추가 점검

- 표마다 쓰는 곳 수를 센다 (`grep -rn "<엔티티>Repository\." | grep -v "find\|delete\|count\|exists"` 류). **0곳이면 그 표는 아무도 안 채운다.**
- 복사할 대상은 **목록 화면이 쓰는 쿼리와 같은 규칙**으로 열거한다. 소유자·버전별로 다른 기준표를 읽는 비대칭이 있으면 복사도 같은 비대칭을 따라야 한다.
- "최신 버전" 같은 선택은 도메인의 정본 순서 상수로 한다 (문자열 max 는 업무 순서와 다르다).

### ⑥ 판정 표기

모든 판정 문장에 근거를 붙이고 셋 중 하나로 표기한다 — **확인됨**(파일:라인·쿼리 결과·실행 로그) / **추정**(근거 부족을 문장에 명시) / **미확인**(안 봤음).
"AS-IS 에 없다 / 대상이 아니다" 같은 **닫는 판정은 여는 판정보다 강한 근거**가 필요하다 — `-a` 재검색·폐쇄 경고 0·미개봉 0 을 확인한 뒤에만 쓴다.
