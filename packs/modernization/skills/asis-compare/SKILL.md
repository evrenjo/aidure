# AS-IS ↔ TO-BE 정합 대조

입력: 레거시 파일(경로 또는 `{{ws:vars.asis.sourceRoot}}` 기준 파일명) · 진입점(모르면 비워 둔다) · TO-BE 파일(서비스·쿼리).
먼저 `.agents/rules/modernization--20-asis-parity-procedure.md` 를 읽는다. 도구 상세는 `packs/modernization/docs/asis-tools.md`.

```bash
B=packs/modernization/bin
```

## 1. 무엇을 대조하는지 한 줄로

"<화면/배치 이름> 의 <생성·수정·복사·조회> — AS-IS <파일>(<진입점>) ↔ TO-BE <클래스#메서드>" 처럼 적는다.
고객 요구 티켓이 있으면 먼저 읽는다 — **티켓이 요구한 동작이 AS-IS 정합보다 우선**이고, 그 경우 표의 판정은 "티켓 기준" 으로 적는다.

## 2. 진입점을 닫는다

1. 진입점을 모르면 `node $B/asis-reads.js <파일>` → 추천 조합을 쓴다. 쓰기 쪽은 `node $B/asis-effects.js <파일>` 의 후보 목록.
2. `node $B/asis-effects.js <파일> --entry <조합>` 를 돌려 **`⚠ 폐쇄 밖 쓰기` 가 0** 이 될 때까지 진입점을 넓힌다.
   다만 폐쇄 밖 쓰기가 **대조 대상과 무관한 다른 기능**이면 그 이유를 적고 멈춘다 (예: 같은 파일의 삭제 기능).
3. `asis-reads.js` 도 `⚠ 폐쇄 밖 읽기` 와 `⚠ 정의 없는 레코드` 를 같은 방식으로 정리한다.

## 3. 표 집합 → 컬럼 → 조건 순서로 뽑는다

병렬 에이전트를 쓸 수 있으면 아래 세 갈래를 나눠 맡긴다 (서로 파일을 고치지 않으므로 충돌이 없다). 없으면 순서대로.

| 갈래 | 명령 | 산출 |
|---|---|---|
| 표 집합 | `node $B/asis-effects.js <파일> --entry … --tobe <TO-BE 가 쓰는 표(AS-IS 이름),…> --cond` | AS-IS 에만 / TO-BE 에만 있는 표 |
| 컬럼 값 | INSERT/UPDATE 문을 열어 컬럼 목록을 옮기고, 컬럼마다 `node $B/asis-field-writes.js <파일> --entry … --field <필드> --table <표>` | 컬럼별 경로 끝 값 + 조건 |
| 읽기 조건 | `node $B/asis-reads.js <파일> --entry … --sql` → `node $B/asis-tobe-map.js <VIEW>.<COL>` (`--where` 로 필터 여부) → `node $B/asis-tobe-diff.js --asis <파일> --entry … --tobe <TO-BE 파일>` | 공통 / AS-IS 만 / TO-BE 만 조건 |

TO-BE 쪽 표 이름은 `asis-tobe-map.js <AS-IS 표>` 로 서로 잇는다. TO-BE 가 그 표를 쓰는 곳 수도 센다 — 0곳이면 아무도 채우지 않는 표다.

## 4. 정합표

| 대상(표·컬럼·조건) | AS-IS (근거 파일:라인) | TO-BE (근거 파일:라인) | 판정 | 표기 |
|---|---|---|---|---|
| `DTL.NUM_UNITS` | 복사 직후 0, 이후 재계산 값 (`X.egl:5327`, `:6024`) | 원본 값 복사 (`CopyService.java:88`) | 다름 | 확인됨 |

- **표기** — **확인됨**: 근거(파일:라인·쿼리 결과·실행 로그)를 같이 적는다 / **추정**: 근거가 부족함을 칸에 적는다 / **미확인**: 안 봤다고 적는다. 빈칸으로 두지 않는다.
- 대입문이 없는 컬럼은 초기화 기본값(공백·0)이 AS-IS 값이다.
- 조건부 대입이면 조건을 칸에 함께 적는다.
- "AS-IS 에 없다" 는 `grep -a` 재검색 + 폐쇄 경고 0 + 미개봉 0 을 확인한 뒤에만 쓴다. 아니면 **미확인**.
- 가능하면 마이그레이션 실데이터 분포(`GROUP BY 컬럼`)로 한 번 교차 확인하고 쿼리·건수를 적는다.

## 5. 보고

결론 한 줄(다른 항목 N개 / 확인됨 M · 추정 K · 미확인 J) → 정합표 → 다른 항목별 수정 제안(파일 단위).
사람이 정해야 하는 것(티켓과 AS-IS 가 충돌 등)은 **선택지 질문**(권장안을 첫째에, 2~4개)으로 묻고, 답을 받기 전에는 고치지 않는다.
