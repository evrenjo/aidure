# SCH1.INVV (fixture)

```sql
CREATE VIEW SCH1.INVV(ID_FSC,
ID_PROF,
TAG_DELETE,
CD_STATUS,
DSC_CALC) AS
SELECT
    T1.ID_FSC,
    T1.PROFILE_CD,
    T1.DELETED_IN,
    T2.STATUS_CD,
    T1.DSC_A || T2.DSC_B
FROM
    SCH0.ITEM T1,
    SCH0.PROFILE T2
WHERE
    T1.PROFILE_CD = T2.PROFILE_CD
    AND T1.DELETED_IN = ''
;
```
