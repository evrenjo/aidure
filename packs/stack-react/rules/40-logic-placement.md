## React 컴포넌트 책임 · 로직 위치

공통 원칙은 clean-code 팩 「레이어 책임 · 공통 로직 추출」. 폴더 배치는 「React 구조·쿼리·URL·폼·다이얼로그 구현」 의 표와 프로젝트 관례가 먼저다.

- 컴포넌트는 props · 상태로 화면을 그리고 이벤트를 연결만 한다. 렌더 중 계산은 순수하게.
- 컴포넌트 파일 안 보조 함수는 그 컴포넌트만 쓰는 짧은 것만. 상태 · Effect 를 쓰는 로직이 길어지면 `useX` 훅으로, Hook 을 안 쓰는 계산 · 형식화는 일반 함수(`getX` · `formatX`)로 꺼낸다 (Hook 을 부르지 않으면 `use` 를 붙이지 않는다).
- **위치는 쓰는 곳 가까이가 기본:** 한 기능 전용은 그 기능 폴더 안의 `hooks` · `utils` · `api` · `components`, 여러 기능 공용은 프로젝트의 공용 폴더, 외부 라이브러리 감싸기는 `lib/`.
- 기능 폴더끼리 서로 import 하지 않는다. 공용 → 기능 → 앱 한 방향.
- 상수는 그 기능의 `constants.ts`, 화면 문구는 프로젝트의 i18n 관례.
- 서버 데이터 호출 · 응답 변환을 컴포넌트에 직접 쓰지 않는다. 기능의 `api` 와 데이터 훅으로.
- 작은 중복마다 훅을 만들지 않는다. 한 줄 감싸기 훅을 만들지 않는다.
