## 프로토타입이 있는 화면 구현

기획 repo 에 프로토타입(화면 목록의 「프로토타입」 칸 · `30-screens/prototype/`)이 있는 화면은 **프로토타입이 화면의 정본**이다. 구현은 테마 토큰(색 · 글꼴)만이 아니라 구성 · 스타일을 따른다.

- 따를 것: 영역 배치 · 타일 · 카드 머리(아이콘 · 제목 · 동작) · 상태 칩과 그 색 · 막대 · 그래프 · 간격 · 빈 값 · 오류 · 로딩 모양. 디자인 시스템의 기본 목록 · 표로 바꾸지 않는다. 같은 모양을 공용 컴포넌트로 만든다.
- 실제 데이터 모양 · API 때문에 다르게 만든 곳은 `| 프로토타입 요소 | 구현 | 다른 이유 |` 표로 보고하고 MR 본문에 남긴다. 이유를 댈 수 없는 차이는 고친다.
- 완료 전에 같은 폭(PC · 폰) 스크린샷을 나란히 본다: `kedovi screens compare <화면 ID>` (화면 진입점 `@spec` 줄에 `@route /경로`). 리뷰 위임 지시서에 비교표와 스크린샷 경로를 넣는다.
- 프로토타입이 틀려 보이면 구현에서 바꾸지 않고 기획 쪽에 묻는다 (결정 기록).
