## 프로세스 경계부터 확인한다

웹 기술 셸은 **권한 있는 쪽**(메인 프로세스·네이티브 코어)과 **웹뷰 쪽**(화면)으로 나뉜다. 웹뷰 쪽은 XSS 한 번이면 공격자 코드가 된다고 보고 설계한다 — 웹뷰에 로컬 권한이 닿아 있으면 XSS 가 원격 코드 실행이 된다.
고치기 전에 그 프로젝트의 현재 설정을 읽어 둔다 — 창 생성 옵션, 프리로드·브리지 파일, 권한 설정 파일, CSP 가 어디서 오는지.

## 창·웹뷰 설정 — 약하게 만들지 않는다

| 항목 | 유지할 상태 |
|---|---|
| 웹뷰 안의 Node·네이티브 API 직접 접근 | **끔**. 필요한 기능은 브리지로 좁게 노출 |
| 컨텍스트 격리(브리지와 페이지 스크립트 분리) | **켬** (끄면 샌드박스도 함께 꺼지는 셸이 있다) |
| 렌더러 샌드박스 | **켬** |
| 웹 보안(동일 출처 정책) · 안전하지 않은(HTTP) 콘텐츠 허용 · 실험 기능 · 블링크 기능 추가 | **기본값 유지** |
| 임베드 웹뷰 태그 | 쓰지 않는 게 기본. 쓰면 생성 직전에 옵션을 검사해 위 항목을 강제하고, 팝업 허용을 켜지 않는다 |
| 로드하는 콘텐츠 | 앱 번들 또는 HTTPS. `file://` 대신 커스텀 프로토콜을 권장하는 셸이면 그쪽 |

이 중 하나를 바꾸자는 변경이 필요해 보이면 **멈추고 이유와 대안을 먼저 묻는다.** 대개 브리지에 함수 하나를 더하는 것으로 해결된다.

## 브리지·IPC

- **기능 단위로 노출한다** — `saveReport(data)` 는 되고 범용 `invoke(channel, ...args)`·파일 시스템·셸 객체를 통째로 넘기는 것은 안 된다. 셸 API 객체 자체를 웹 콘텐츠에 넘기지 않는다.
- **받는 쪽에서 검증한다** — 보낸 프레임·출처가 기대한 것인지(보낸 쪽 정보로 확인), 인자 타입·범위·경로가 허용 범위인지. 경로 인자는 정규화 후 허용 루트 밖이면 거부한다.
- 응답에 비밀·전체 파일 경로·내부 오류 원문을 싣지 않는다.

## 권한 모델이 있는 셸 (capability·permission·scope 류)

- **새 명령은 필요한 창에만, 가장 좁은 범위로** 허용한다. 와일드카드 범위를 넓히지 않는다.
- 한 창이 여러 권한 묶음에 속하면 **권한이 합쳐진다** — 새 묶음을 만들 때 그 창에 이미 붙은 묶음을 확인한다.
- 권한 폴더의 파일이 **자동으로 모두 켜지는** 셸이 있다. 설정에서 명시 목록으로 바꾼 뒤에는 목록에 없는 파일이 무시된다 — 어느 방식인지 먼저 본다.
- **원격 URL 에 명령 접근을 여는 설정은 쓰지 않는 게 기본**이다. 일부 플랫폼은 원격 페이지 안의 iframe 과 창 자체를 구분하지 못한다고 문서에 적혀 있다.
- 의존성이 많은 화면이면 IPC 메시지를 코어에 닿기 전에 검사하는 격리 계층(isolation 패턴)이 있는지 보고, 있으면 우회하지 않는다.
- 플랫폼별 권한은 플랫폼 조건으로 좁힌다(데스크톱에만 필요한 권한을 모바일 빌드에 싣지 않는다).

## CSP·내비게이션·새 창·외부 링크

- **CSP 를 둔다** — 스크립트는 `'self'` 기준, `unsafe-eval`·원격 스크립트(CDN) 출처를 더하지 않는다. WebAssembly 가 필요하면 `'wasm-unsafe-eval'` 만. 개발 서버용 완화는 개발 빌드에만. 셸이 번들 스크립트에 해시·nonce 를 자동으로 넣는지 확인하고 그 방식을 깨지 않는다.
- **내비게이션과 새 창을 제한한다** — 앱 출처가 아닌 이동은 막고, 새 창 생성 처리기에서 허용 목록 외에는 거부한다. URL 은 문자열 비교가 아니라 URL 파서로 출처를 확인한다.
- **외부 열기 API 에 신뢰할 수 없는 값을 넘기지 않는다** — 프로토콜 처리기를 거쳐 임의 명령이 실행될 수 있다. `https`·`mailto` 등 허용 스킴만.
- 웹뷰의 권한 요청(카메라·마이크·알림·위치 등)은 처리기를 두어 **기본 거부**, 필요한 출처·권한만 허용한다.

## 셸 런타임·빌드

- 셸 런타임은 **지원되는 최신 계열**을 유지한다 — 내장 브라우저 엔진 보안 패치가 여기에 묶인다.
- **빌드 퓨즈(빌드 때 고정하는 기능 스위치)** 를 약하게 바꾸지 않는다 — 런타임을 일반 Node 로 실행하는 스위치·명령줄 디버그·환경 변수 옵션은 배포 빌드에서 끄고, 번들 무결성 검사·"번들에서만 로드"는 켠 상태를 유지한다.
- 검증: 개발자 도구 콘솔의 CSP 위반·보안 경고 0, 브리지에 없는 채널·권한 밖 명령 호출이 거부되는지, 외부 링크가 기본 브라우저로 열리는지 한 번씩 확인.
