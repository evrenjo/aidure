## 데스크톱 앱 기본 원칙 (프레임워크 무관)

데스크톱 코드를 고치기 전에 확인한다. 절차·예시는 작업별 desktop 룰.

- **프로젝트의 기존 구조를 따른다** — 화면·로직 분리 방식(MVVM 등), IPC 채널 모양, 저장 위치를 먼저 찾아 맞춘다. 새 패턴·라이브러리는 묻고 들인다.
- **UI 는 UI 스레드에서만 만지고, UI 스레드에서 기다리지 않는다** — 파일·네트워크·DB·무거운 계산은 백그라운드로, 결과만 UI 스레드로 돌려보낸다.
- **화면과 로컬 권한 사이는 좁은 IPC 경계다** — 화면 쪽은 신뢰하지 않는다. 기능 단위 채널만 열고, 보낸 쪽과 인자를 받는 쪽에서 검증한다. 범용 "명령 실행·파일 읽기" 통로를 만들지 않는다.
- **원격 콘텐츠에 로컬 권한을 주지 않는다** — 외부 URL·사용자 HTML 을 파일·프로세스 접근이 가능한 창에 싣지 않는다. 외부 링크는 기본 브라우저로 열되 스킴을 확인한다.
- **서명·업데이트 무결성을 약하게 만들지 않는다** — 서명 검증·HTTPS·업데이트 서명 확인을 끄거나 우회하는 변경은 하지 않는다. 서명 키·인증서는 저장소에 넣지 않는다.
- **경로는 OS API 로 얻는다** — 사용자 데이터·설정·캐시·로그는 OS 가 정한 위치에, 설치 폴더에는 쓰지 않는다. 경로 조립은 경로 API 로(구분자·대소문자·긴 경로 차이).
- **비밀은 OS 자격 증명 저장소에** — 토큰·비밀번호를 평문 설정 파일·로그에 두지 않는다. 저장소가 없는 환경의 대체 동작을 확인한다.
- **크래시·로그에 개인정보를 싣지 않는다** — 경로 속 사용자명, 입력값, 토큰을 걸러 보낸다. 수집은 사용자 동의 정책을 따른다.
- **키보드·보조기기·고해상도에서 동작해야 한다** — 표준 컨트롤, 모든 컨트롤에 접근 가능한 이름, 논리 단위 크기(픽셀 하드코딩 금지).
- **OS 셋 중 하나만 확인했으면 "다른 OS 미확인"이라고 적는다.**
