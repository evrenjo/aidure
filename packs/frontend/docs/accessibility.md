# 접근성 기준 상세 (WCAG 2.2 A·AA · APG 패턴)

요약 규칙은 `packs/frontend/rules/70-keyboard-a11y.md`. 키보드 구현 세부(포커스 링 CSS · 탭 정지 · 표 행 링크 · 드롭다운)는 `packs/frontend/docs/keyboard-a11y.md`.
이 문서는 **화면을 만드는 사람이 실제로 걸리는 성공 기준**을 작업 단위로 묶은 것이다. 출처는 `packs/frontend/docs/SOURCES.md`.

> 기준선은 WCAG 2.2 **A + AA** 다. 1.4.6(대비 7:1)·2.4.12·2.4.13·3.3.9 는 AAA 라 기본 요구가 아니다.
> 프로젝트가 다른 수준(법적 요구·고객 계약)을 정했으면 그것을 따른다.

## 2. 시맨틱 HTML 이 먼저인 이유

W3C *Using ARIA* 의 첫 규칙 — 네이티브 요소가 그 의미와 동작을 이미 가지고 있으면 그것을 쓴다.

| 만들고 싶은 것 | 쓴다 | 쓰지 않는다 |
|---|---|---|
| 이동 | `<a href>` (새 탭·주소 복사가 된다) | `div onClick` + `location` |
| 동작 | `<button type="button">` | `span role="button"` + 키 처리 직접 구현 |
| 켜기/끄기 | `<input type="checkbox">` 또는 `button aria-pressed` | 클릭되는 `div` |
| 하나 고르기 | `<input type="radio">` 묶음 · `<select>` | 스타일만 입힌 목록 |
| 펼침 | `<details>`/`<summary>` 또는 `button aria-expanded` | |
| 모달 | `<dialog>` + `showModal()` (배경을 자동 `inert`, Esc 닫기) 또는 검증된 공용 모달 | 포커스 관리 없는 `div` 오버레이 |
| 표 데이터 | `<table>` + `<th scope>` + `<caption>` | `div` 격자 (행·열 관계가 사라진다) |

- ARIA 는 의미만 바꾸고 **동작은 주지 않는다** — `role="button"` 을 달면 Enter·Space·포커스를 직접 구현해야 한다.
- 네이티브 의미를 덮지 않는다(`<h2 role="tab">` 대신 `div role="tab"` 안에 `h2`).
- 레이아웃에 `<table>` 을 쓰지 않는다. 표를 격자 위젯(`role="grid"`)으로 만들 때는 APG grid 패턴의 방향키 이동까지 구현해야 하므로, 셀 편집·방향키 이동이 필요 없으면 일반 표로 둔다.

## 3. 위젯 패턴 (WAI-ARIA APG)

| 패턴 | 핵심 |
|---|---|
| **모달 다이얼로그** | 열면 포커스가 안으로(기본은 첫 포커스 가능 요소, 긴 본문이면 제목·첫 문단에 `tabindex="-1"`, **파괴 동작 확인창이면 덜 파괴적인 버튼(Cancel)**). Tab 은 안에서 순환, Esc 로 닫힘, 닫히면 연 요소로(그 요소가 사라졌으면 논리적인 다음 자리). `aria-modal="true"`, 보이는 제목을 `aria-labelledby` 로. 닫기 버튼을 항상 둔다 |
| **탭** | `tablist`/`tab`/`tabpanel`, `aria-selected`·`aria-controls`. Tab 은 탭 목록에 한 번 들어가고(선택된 탭) 나간다. ←→(세로면 ↑↓)로 이동·끝에서 순환, Home/End 선택. 패널 내용이 즉시 뜨면 포커스 이동과 함께 선택(자동), 늦으면 Enter/Space 로 선택(수동) |
| **콤보박스(자동완성)** | DOM 포커스는 입력칸에 두고 `aria-activedescendant` 로 목록 항목을 가리킨다. `aria-expanded`·`aria-controls`·`aria-autocomplete`. ↓ 로 목록 진입, Esc 로 목록 닫기, Enter 로 선택 |
| **메뉴 버튼** | 버튼 `aria-haspopup`·`aria-expanded`, 항목은 `menuitem`, 방향키 이동, Esc 로 닫고 버튼으로 복귀. 단순 링크 목록이면 메뉴 역할을 주지 말고 링크 목록으로 |
| **펼침(disclosure)** | 버튼 + `aria-expanded` + 대상. 아코디언도 같은 원리 |
| **툴팁** | 포커스·호버로 뜨고 Esc 로 닫힘, 1.4.13 세 조건. 툴팁 안에 상호작용 요소를 넣지 않는다(그건 팝오버·다이얼로그) |
| **포커스 관리 방식** | 복합 위젯은 roving tabindex(선택 항목만 `tabindex=0`) 또는 `aria-activedescendant` 둘 중 하나 |

## 4. 알림·상태 메시지 (라이브 영역)

- 라이브 영역(`role="status"` = polite, `role="alert"` = assertive, 또는 `aria-live`)은 **내용을 바꾸기 전에 DOM 에 있어야 한다.** 알림 컴포넌트를 조건부로 새로 그리면 읽히지 않는 경우가 많다 — 빈 컨테이너를 앱 루트에 두고 내용만 바꾼다.
- 기본은 polite. assertive(`alert`)는 즉시 알아야 하는 오류에만 — 남발하면 사용자가 하던 낭독을 끊는다.
- 검색 결과 건수·저장됨·업로드 진행은 status. 토스트 컨테이너는 status 영역으로.
- 포커스를 옮겨야 하는 경우(제출 오류 요약, 라우트 변경)와 옮기지 않아야 하는 경우(상태 알림)를 구분한다.

## 5. 클라이언트 라우팅 (SPA)

서버 왕복 없는 화면 전환은 스크린리더에 아무 신호도 주지 않는다.

1. 문서 `<title>` 을 새 화면으로 바꾼다.
2. 포커스를 새 화면의 시작점으로 옮긴다 — 사용자 테스트에서 **제목(또는 작은 바로가기 링크)에 포커스를 주는 것**이 가장 효과적이었다. 큰 래퍼에 포커스를 주면 확대 사용자에게 스크롤이 튄다.
3. 필요하면 라이브 영역으로 "Order details page" 처럼 알린다(라이브 영역만으로는 브라우저·보조기기 조합에 따라 부족했다).
4. 뒤로가기로 돌아오면 이전 스크롤·포커스 위치를 복원한다.

## 6. 이미지·아이콘·미디어

| 이미지 | 대체 텍스트 |
|---|---|
| 정보 전달 | 뜻을 짧게 ("2026년 분기별 매출 추이, 3분기 최고") |
| 장식 · 곁 글자와 중복 | `alt=""` (속성 자체를 빼지 않는다 — 빠지면 파일명을 읽는다) |
| 링크·버튼 안 이미지 | 동작·목적지 ("Home", "Download invoice") |
| 글자가 든 이미지 | 그 글자 (다른 곳에 같은 글자가 있으면 `alt=""`) |
| 차트·도표 | 짧은 `alt` + 같은 정보를 본문·표로 |

- 인라인 SVG 아이콘: 장식이면 `aria-hidden="true"`, 단독이면 부모 버튼에 이름.
- 영상은 자막(1.2.2), 자동 재생 소리 금지(1.4.2).

## 7. 표

- `<th>` + `scope="col"/"row"`, 표의 주제는 `<caption>`(시각적으로 숨겨도 된다). 병합 머리글이 있는 복잡한 표는 `headers`/`id`.
- 정렬 가능한 열 머리글은 버튼 + `aria-sort`.
- 선택 체크박스 열은 행마다 이름("Select order 1024")과 전체 선택 체크박스를 둔다.
- 좁은 폭에서 표는 가로 스크롤이 허용되는 예외(1.4.10) — 스크롤 영역에 이름과 포커스를 준다(`keyboard-a11y.md` §스크롤 영역).

## 8. 움직임·시각 설정

- `prefers-reduced-motion: reduce` 이면 확대·패닝·회전·시차 스크롤을 줄이거나 페이드로 **바꾼다**(모두 없애는 것보다 대체가 낫다).
- 5초 넘게 스스로 움직이는 것(캐러셀·자동 스크롤)은 멈춤 수단(2.2.2).
- 강제 색상 모드(`forced-colors`)에서 테두리·포커스가 사라지지 않게 — 배경색만으로 그린 경계는 사라진다.
- 다크 모드는 토큰으로. 두 모드 모두 대비를 확인한다.

## 9. 검사 순서

1. 린트 — 프레임워크 접근성 린트를 error 로.
2. 자동 검사 — axe(브라우저 확장·테스트 통합)·Lighthouse. 자동 검사는 문제의 일부만 잡는다.
3. 키보드 한 바퀴 — Tab·Shift+Tab·Enter·Space·Esc·방향키로 모든 동작, 포커스가 늘 보이고 가려지지 않는지.
4. 확대 — 200% 와 320px 폭에서 잘림·겹침·가로 스크롤.
5. 스크린리더 — 화면을 크게 바꿨으면 한 번 듣는다(VoiceOver·NVDA). 절차는 `keyboard-a11y.md`.
