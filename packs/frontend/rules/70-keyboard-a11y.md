기준선은 **WCAG 2.2 AA**. 프로젝트가 다른 수준을 정했으면 그것을 따른다.

## 시맨틱 HTML 먼저, ARIA 는 그다음

- 네이티브 요소가 그 역할을 하면 그것을 쓴다 — 이동은 `<a href>`, 동작은 `<button>`, 입력은 `<input>`·`<select>`·`<textarea>`. `div` + `onClick` + `role="button"` 을 만들지 않는다(ARIA 첫째 규칙). 네이티브 의미를 ARIA 로 바꾸지 않는다.
- ARIA 로 만든 위젯은 **키보드 동작까지 함께** 구현한다 — 패턴은 WAI-ARIA Authoring Practices(APG)의 해당 패턴(탭·메뉴·콤보박스·다이얼로그·그리드)을 따른다. 틀린 ARIA 는 없는 것보다 나쁘다.
- 페이지 구조를 드러낸다 — `<html lang>`, 화면마다 고유한 `<title>`, 제목 계층(`h1`~`h6` 건너뛰지 않기), 랜드마크(`header`·`nav`·`main`·`footer`).
- 의미 있는 이미지는 `alt` 로 뜻을, 장식 이미지는 `alt=""`(속성을 빼지 않는다). 링크·버튼 안 이미지는 목적지·동작을, 차트는 같은 정보를 본문·표로도. 아이콘뿐인 버튼·링크는 접근 가능한 이름을 준다.
- 데이터 표는 `<table>` + `<th scope>` + `<caption>`, 정렬 머리글은 버튼 + `aria-sort`. 레이아웃에 표를 쓰지 않는다.
- **보이는 글자가 접근 가능한 이름에 들어간다**(앞부분에, WCAG 2.5.3) — 음성으로 보이는 라벨을 말해 누를 수 있게.
- 포커스·선택만으로 화면을 이동·제출하지 않는다(WCAG 3.2.1·3.2.2). 한 글자 단축키는 끌 수 있거나 포커스 중에만(2.1.4).

## 보이는 것 — 대비·색·크기·움직임

- 글자 대비 4.5:1(큰 글자 3:1), 입력 테두리·아이콘·포커스 표시 같은 필수 비텍스트 3:1(WCAG 1.4.3 · 1.4.11). 디자인 토큰 조합으로 확인한다.
- **색만으로 뜻을 전하지 않는다** — 오류·상태·필수는 글자·아이콘을 함께(WCAG 1.4.1).
- 포인터 대상은 최소 24×24 CSS px 이거나 그만큼 간격(WCAG 2.5.8). 끌기로만 되는 동작에는 클릭 대안(WCAG 2.5.7).
- **포커스된 요소가 고정 헤더·스티키 바·쿠키 배너에 가려지지 않게** 한다(WCAG 2.4.11) — `scroll-padding` 등으로 여유를 준다.
- 움직임은 `prefers-reduced-motion` 을 따른다 — 확대·패닝·회전을 페이드 등으로 바꾼다. 5초 넘게 스스로 움직이는 것은 멈출 수 있게, 초당 3회 넘는 깜빡임 금지.
- **툴팁·팝오버**(WCAG 1.4.13) — Esc 로 닫히고, 포인터를 그 위로 옮겨도 유지되고, 스스로 사라지지 않는다. 툴팁 안에 누를 것을 넣지 않는다(그건 팝오버·다이얼로그).
- 글자 200% 확대·글자 간격 조정에서 잘리지 않게 고정 높이 상자에 글자를 가두지 않는다(1.4.4 · 1.4.12).

## 키보드

기준은 Tab 으로 이동, Enter/Space 로 실행.

- **포커스 표시는 `outline` 공용 클래스 하나로**, `:focus` 가 아니라 `:focus-visible`. 스크롤 컨테이너 안은 음수 offset. box-shadow 링은 입력칸 테두리와 겹친다.
- **DOM 순서 = Tab 순서.** 양수 `tabindex` 금지. 본문 바로가기는 라우팅 때 포커스를 받는 스크롤 컨테이너 안에 두고 스크롤 없이 포커스를 옮긴다.
- **표 행은 행 전체 클릭이 아니라 대표 셀을 진짜 링크(이동) / 버튼(패널 열기)** 으로. 체크박스·인라인 입력 셀은 행 클릭 전파만 막는 공용 래퍼로 감싼다.
- **탭 바는 roving tabindex** — 선택된 탭만 `tabindex="0"`, ←→ 이동(끝에서 순환, Home/End), Enter/Space 선택. `tablist`/`tab`/`tabpanel` + `aria-selected`·`aria-controls`. 키 처리에 조건 없이 선택을 걸면 Tab 키에도 탭이 바뀐다.
- **모달** — 열리면 포커스가 안으로(파괴 동작 확인창이면 덜 파괴적인 버튼, 긴 본문이면 제목), 안에 갇히고, Esc 로 닫히고, 닫히면 연 자리로(그 요소가 사라졌으면 논리적인 다음 자리). 닫기 버튼을 항상 둔다. 네이티브 `<dialog>`+`showModal()` 은 배경 `inert` 와 Esc 를 스스로 한다. 배경은 보조기기에서 숨긴다. 이름은 모달 안 첫 제목(`h1`~`h6`)에 `aria-labelledby` 로 걸게 공용 컴포넌트에서 처리 → 제목은 제목 요소로 그린다.
- **드롭다운에서 다이얼로그를 열 때** 메뉴를 먼저 닫아 포커스를 토글로 돌린 뒤 연다(아니면 닫힌 뒤 복귀 지점이 사라진다). 메뉴 항목은 방향키 목록 등록 + `tabindex` + Enter/Space 처리 셋이 다 있어야 닿는다. 토글 안에 버튼을 넣지 않는다(탭 정지 2개).
- **이름** — 보이는 라벨이면 `<label for>` + `id`, 라벨이 없으면 `aria-label`, 묶음이면 `role="group"` + `aria-labelledby`. `aria-labelledby` 용 id 에 공백 금지. 라벨이 없다고 화면에 라벨을 새로 그리지 않는다. 읽기 전용 값의 캡션은 `<label>` 이 아니다.
- **이름이 사라질 수 있으면 위반** — 아이콘뿐인 버튼, 조건부 렌더로 글자가 빠질 수 있는 버튼.
- **스크롤 영역의 암묵 탭 정지(Chrome 127+)는 없애지 않는다** — 포커스 가능한 자식이 없는 스크롤 영역은 브라우저가 탭 정지로 만든다. `role="group"` + `aria-label` + 포커스 클래스를 준다. 모달 포커스 트랩이 그 영역을 건너뛰면 `tabindex="0"` 까지 준다.
- **스티키 헤더 복제본은 `aria-hidden` + `inert`** — `aria-hidden` 만으론 탭 순서에 남는다.
- 자동 포커스는 기본 금지. 페이지의 전부인 폼(로그인)·사용자가 방금 연 인라인 편집만, 사유 주석과 함께.
- 오류 문구는 `aria-describedby` 로 필드에 잇고, 필수는 `aria-required`.
- **클라이언트 라우팅** 후에는 문서 제목을 바꾸고 포커스를 새 화면의 시작점(본문 컨테이너·첫 제목)으로 옮긴다 — 안 그러면 스크린리더는 화면이 바뀐 줄 모른다.

## 검사

- 자동 검사(axe·Lighthouse 등)는 문제의 일부만 잡는다 — 통과해도 **키보드만으로 한 바퀴**(Tab·Shift+Tab·Enter·Space·Esc·방향키)와 200% 확대를 직접 본다.
- 프레임워크의 접근성 린트(React `jsx-a11y`, Angular `@angular-eslint` template a11y, Vue `vuejs-accessibility` 등)를 error 로 둔다.
- 린트가 못 보는 것(실제 Tab 순회의 탭 정지, 조건부로 사라지는 이름)은 도구로 본다 — React 스택 팩에 정적 라벨 검사기(`check-a11y-labels.py`)와 브라우저 Tab 순회 검사기(`check-a11y-runtime.js`)가 있다. 런타임 검사기는 소스가 아니라 렌더된 DOM 을 본다.
- 화면을 크게 손봤으면 스크린리더로 실제 낭독을 한 번 듣는다(절차는 상세 문서).

- 콤보박스(자동완성)·메뉴 버튼·펼침 등 다른 위젯은 APG 패턴 그대로 — 요약표는 상세 문서.
