## 무엇을 URL 에 두나

| 넣는다 | 넣지 않는다 |
|---|---|
| 페이지 번호·크기, 정렬 키·방향, 검색어, 필터, 탭 | 서버 응답, 로딩 여부, 선택된 행, 다이얼로그 열림 |
| 화면을 재현하는 데 필요한 값 | 타이핑 중인 값 (확정 시에만) |

컴포넌트 상태에만 두면 뒤로가기·새로고침·링크 공유가 깨진다. 로그인으로 튕겼다 돌아올 때도 쿼리·해시까지 싣는다.

## 쓰는 법

**공용 URL 상태 유틸 하나**(`get(key)` · `update(updates, { replace? })` · `clear()`)로만 쓴다. 화면에서 라우터의 쿼리 쓰기 API 를 직접 부르지 않는다(가능하면 린트로 막는다 — 읽기는 허용).

```
page = Number(get("page")) || 1                  // 기본값은 읽는 쪽에서
onSizeChange(size) = update({ size, page: 1 })
```

- **push vs replace** — 사용자가 한 행동(페이지 이동·정렬 클릭·필터·탭 전환·검색 확정·Reset)은 push, 화면이 스스로 채우는 기본값·진입 시 기본 기간·**타이핑 중 검색어**는 replace.
- 목록을 좁히는 것(검색·필터·정렬·크기)을 바꾸면 `page: 1` 을 함께 보낸다.
- **기본값은 URL 에 쓰지 않는다** (`page=1`, 기본 정렬, 첫 탭) — 같은 화면이 두 주소를 갖게 된다.
- 빈 문자열·**숫자** 0 은 삭제, **문자열** `'0'` 은 값이다(검색창에 0 을 친 것).
- 한 화면에 표가 여럿이면 접두어로 가른다(`ovPage`·`stPage`). 같은 화면에서 접두어가 겹치지 않게.
- **입력칸은 URL 을 따라온다** — 진입 때 한 번 읽으면 뒤로가기에서 폼과 결과가 어긋난다. 적용된 조건 키가 바뀌면 다시 채운다. 조건 키에 페이지·크기는 넣지 않는다.
- **탭을 별도 상태로 복사하지 않는다** — URL 에서 파생한다.

## 대상이 아닌 것

다이얼로그 안의 페이지·검색 · "더 보기" 누적 카운터 · 검색 후 그 자리에서 편집하는 화면(뒤로가기가 미저장 편집을 날린다) · 검색이 변경 미리보기인 화면 · 전 행을 한 번에 보이는 상세 표.
