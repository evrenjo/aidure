# 화면

> 상태: 초안

**화면의 정본은 프로토타입이다** (`prototype/` 폴더). 이 문서는 화면 목록 · 화면 정책 · 스크린샷만 둔다. 배치 · 문구를 여기에 다시 쓰지 않는다.
문서 사이트에는 프로토타입을 넣지 않는다 (스크립트가 사이트에서 돌지 않게). 화면마다 스크린샷을 `shots/<화면 ID>.png` 로 두고, 프로토타입은 폴더를 열거나 실행 주소를 아래 표에 적는다.
따로 화면설계서(장 HTML, `_template.html`)가 필요한 프로젝트만 쓴다 (워크스페이스에서는 `screens` 스킬).

## 화면 목록

| 화면 ID | 화면 | 경로(메뉴) | 기능 ID | 프로토타입 | 스크린샷 |
|---|---|---|---|---|---|
| SCR-<영역>-01 | <로그인> | <메뉴 밖> | <FN-AUTH-001> | <prototype/ 의 파일 · 실행 주소> | <shots/SCR-AUTH-01.png> |

- 화면 ID 는 한 번 붙이면 바꾸지 않는다. 없앤 화면은 결번으로 남긴다.
- 기능 ID 마다 화면이 있어야 한다. 화면이 없는 기능은 기능 문서에 「없음」 과 이유.
