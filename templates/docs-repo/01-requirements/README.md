# 요구사항

파일 하나에 요구사항 하나. [_template.md](_template.md) 를 복사해 `REQ-<번호>.md` 로 만든다.

## ID 규칙

- 형식 `REQ-001`, `REQ-002` … 세 자리, 1부터 순서대로.
- **한 번 붙인 번호는 바꾸지도, 재사용하지도 않는다.** 폐기해도 파일은 남기고 상태만 `폐기`.
- 하위 구분이 필요하면 새 번호를 쓰고 `상위 요구사항` 칸에 부모 ID 를 적는다 (`REQ-001-1` 같은 가지 번호는 쓰지 않는다).
