# API

> 상태: 초안

API 계약의 정본이다. 서버 repo 의 OpenAPI 같은 생성물이 있으면 **그것이 정본**이고, 여기에는 목록과 링크만 둔다.

| API ID | 메서드 · 경로 | 기능 ID | 요청 · 응답 |
|---|---|---|---|
| API-<영역>-001 | <GET /orders> | <FN-ORD-001> | <정본 링크 또는 아래 절> |

- 요청 · 응답 모양(봉투 · 오류 코드)은 프로젝트의 기존 관례를 따른다.
- 기능마다 API 가 있어야 한다. API 가 없는 기능은 기능 문서에 「없음」 과 이유.
