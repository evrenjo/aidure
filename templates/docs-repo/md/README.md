# md 사본

`originals/` 의 원본을 에이전트가 읽을 수 있게 옮긴 사본이다. **워크스페이스 `workspace.json` 의 `mdPath` 는 이 폴더(`"mdPath": "md"`)를 가리킨다.**

## 규칙

- 경로는 원본과 같게, 확장자만 `.md` — `originals/화면설계/주문관리.pptx` → `md/화면설계/주문관리.md`
- 파일 맨 위에 출처를 적는다.

  ```markdown
  > 원본: originals/화면설계/주문관리.pptx · 반영: <YYYY-MM-DD>
  ```

- 표는 md 표로, 그림은 설명 문장으로 옮긴다. 옮기지 못한 부분은 `(원본 참조: 3쪽 그림)` 처럼 남긴다.
- 원본이 바뀌면 같은 커밋에서 사본도 고친다. 사본만 따로 고치지 않는다 (원본과 어긋난다).
- 원본에서 없어진 파일은 사본도 지운다.
