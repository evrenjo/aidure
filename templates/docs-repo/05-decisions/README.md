# 결정 기록

요구사항·정책을 정하면서 내린 결정을 남긴다. [_template.md](_template.md) 를 복사해 `DEC-<번호>.md` 로 만든다.
번호는 바꾸지 않는다. 결정을 뒤집으면 새 결정을 만들고 이전 결정의 상태를 `대체됨(DEC-000)` 으로 둔다.

이 표에는 결정 한 줄과 정본 링크만 둔다. 대안 · 이유 · 영향은 각 결정 파일에, 날짜 · 개정 경위는 그 파일 끝 「결정 경위」 에 쓴다.

| ID | 결정 | 정본 | 상태 |
|---|---|---|---|
| <DEC-001> | <한 줄> | [DEC-001.md](DEC-001.md) | <유효> |
