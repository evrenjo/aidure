# 결정 · 미결

결정을 내리면 [_template.md](_template.md) 를 복사해 `DEC-<번호>.md` 로 남긴다. 정하지 못한 것은 [미결 목록](open-questions.md) 한 곳에 둔다.
결정 · 개정 경위는 기능 · 화면 문서 본문에 쌓지 않는다. 그 문서에서는 결정 ID 로 가리킨다.

| 상태 | 뜻 |
|---|---|
| 제안 | 논의 중. 개발 근거로 쓰지 않는다 |
| 확정 | 개발 근거로 쓴다 |
| 대체됨(DEC-000) | 새 결정으로 바뀌었다. 파일은 남기고 새 결정 ID 를 적는다 |

이 표에는 결정 한 줄과 링크만 둔다.

| ID | 결정 | 상태 |
|---|---|---|
| <DEC-001> | <한 줄. ID 를 결정 파일 링크로> | 제안 |
