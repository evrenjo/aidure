# 화면 목록

> 상태: 초안

화면설계서의 장(`*.html`)과 이 목록이 짝이다. 장 양식은 `_template.html` 을 복사해 시작한다
(워크스페이스에서는 `screens` 스킬이 순서를 안내한다).

- 화면 ID 는 한 번 붙이면 바꾸지 않는다. 없앤 화면은 결번으로 남긴다.
- 기능 ID 마다 화면이 있어야 한다. 화면이 없는 기능은 「화면 없음」 과 이유를 적는다.
- 장을 고치면 이 목록의 기능 ID 도 같은 커밋에서 맞춘다.

| 화면 ID | 화면 | 경로(메뉴) | 기능 ID | 모바일 |
